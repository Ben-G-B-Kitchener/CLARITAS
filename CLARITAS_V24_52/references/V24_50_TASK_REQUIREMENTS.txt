CORE FIX — CUDA/REFERENCE INPUT PARITY
======================================================================

Audit every scalar parameter passed into the CUDA geometry/local-replay validation kernels.

For every scalar parameter that production CUDA receives as float32, the independent high-precision validator must use the exact same quantized VALUE as its input.

    Rin_ref  = float(np.float32(Rin))
    Rout_ref = float(np.float32(Rout))
    Zmin_ref = float(np.float32(Zmin))
    Zlow_ref = float(np.float32(Zlow))
    Zmax_ref = float(np.float32(Zmax))

DO NOT simply apply this illustrative list blindly.

- float32 scalar;
- float64 scalar;
- integer;
- pointer/array;
- other type.

The reference must mirror the VALUE DOMAIN of the production launch exactly.

The principle is:

    SAME INPUT VALUE AS CUDA
    +
    HIGHER-PRECISION INDEPENDENT MATHEMATICS

not:

    ORIGINAL UNQUANTIZED PYTHON INPUT
    +
    HIGHER-PRECISION MATHEMATICS

These are not equivalent for grazing geometry.

DO NOT QUANTIZE THE REFERENCE MATHEMATICS
======================================================================

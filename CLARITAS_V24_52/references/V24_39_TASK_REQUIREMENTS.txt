4. ROOT CAUSE TO INVESTIGATE AND CORRECT
======================================================================

The current diagnosis is that V24.38 implements the Smith height random walk with inside/outside flipping, but its Beckmann VNDF sampling remains effectively restricted to the upper hemisphere.

You MUST verify this diagnosis against the actual source before modifying it.

Relevant V24.38 logic includes code conceptually equivalent to:

    float wix = -(*dx);
    float wiy = -(*dy);

THE REFERENCE BUG
======================================================================

Audit the V24.51 independent one-step reference.

It currently appears to contain logic equivalent to:

    if abs(vz) < tolerance:
        t = finite_cylinder_hit(...)
        return wall_surface

or otherwise assumes that a horizontal water/headspace ray cannot hit the free surface.

That is physically wrong for a radially varying free surface.

For a ray:

    p(t) = (x0 + vx*t,
            y0 + vy*t,
            z0)

the radial coordinate:

    r(t) = sqrt((x0+vx*t)^2 + (y0+vy*t)^2)

changes with t.

Therefore a surface defined by:

    z0 = free_surface_z(r)

can be crossed by a horizontal ray.

Correct the independent host/reference implementation.
